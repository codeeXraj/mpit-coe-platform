## 📞 Support

If any error appears:

1. **Clear node_modules**
   ```bash
   rm -rf node_modules
   npm install
   ```

2. **Clear .next cache**
   ```bash
   rm -rf .next
   npm run dev
   ```

3. **Check all files exist**
   - globals.css
   - Header.tsx
   - HeroSection.tsx
   - CourseCard.tsx
   - StatsCounter.tsx
   - Footer.tsx
